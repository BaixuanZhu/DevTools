# Markdown 导出 HTML 预览与多主题

## Goal

Markdown 工作台导出 HTML 前可弹窗预览真实产物，内置多套主题（经典浅色/暗色/微信公众号/极简衬线/科技蓝）并支持在预览与导出文件内随时切换，导出文件保持零外部依赖

## Background

- 现状：导出下拉点「HTML（.html）」直接触发下载；`markdown-export.ts` 套写死的浅色 zinc 模板，无预览、无主题选择。
- 导出产物定位：单文件、可直接打开/分享，不接受任何外部网络依赖（现有契约）。

## Requirements

1. **导出前预览**：点「HTML（.html）」不再直接下载，先弹出「导出 HTML」对话框：
   - 对话框内可切换主题，预览区与最终导出文件渲染完全一致（同一产物生成函数）；
   - 对话框底部提供「下载 HTML」与「取消」。
2. **导出文件烘焙所选主题**（2026-09-01 二轮反馈修订：对话框顶部已承担主题选择，产物不再内嵌切换器）：
   - 单文件零外部依赖且完全静态（无外部 CSS/JS/字体/图片、无任何脚本），双击即可打开；
   - 产物只包含预览时选定的那一套主题（变量段 + 可选附加规则）。
3. **主题集（5 套，二轮反馈修订）**：经典浅色（迁移现有观感）、极光渐变（全新，渐变标题特色，替代原「暗色」）、微信公众号、极简衬线、科技蓝（重做：开发者社区风标题侧边条 + 深色代码块）。
4. **预览对话框层级**：必须压过 md-editor-v3 内部弹层（其 dropdown/modal z-index 达 20000-20001），否则被编辑器元素覆盖。
5. **兼容与安全约束**：
   - `.md` / PDF 导出流程不变；
   - 导出 HTML 渲染能力与现状持平（marked GFM；代码高亮、katex/mermaid 渲染不在本轮范围）；
   - 预览 iframe 全沙箱（禁脚本）；产物本身无脚本。

## Acceptance Criteria

- [ ] 工具栏点 HTML 弹出预览对话框；切换 5 套主题预览即时更新；对话框层级高于编辑器全部弹层。
- [ ] 下载的 HTML 渲染 = 预览所选主题；产物无脚本、无外链，单主题变量段。
- [ ] 导出文件无任何外部网络引用（无 `http(s)://` 的 css/js/字体请求）。
- [ ] markdown-export 新增单测覆盖主题注册表与产物构建；`pnpm test` / `pnpm astro check` / `pnpm build` 全绿。

## Out of Scope

- 导出 HTML 的代码高亮、KaTeX/Mermaid 渲染（后续任务）；
- 用户自定义主题色板；
- PDF/.md 导出体验变更。
